# OpenClaw

Configure the local stdio MCP server with OpenClaw's MCP registry and restart or reload the
Gateway. The installer prints the exact command and absolute executable path.

When the current message tool exposes presentation actions, map `presentation.actions` to native
buttons or cards and preserve each action `id`/`value` unchanged. If the tool does not advertise
the required action shape, send `presentation.fallback_text` instead. Button callbacks are
treated as the action value and still require the active card ID and review count before calling
`vocab_coach_review`.

OpenClaw owns channel plugins, credentials, allowlists, target chats, and cron. A channel plugin
may be absent or disabled; report that setup prerequisite and use text when possible.
