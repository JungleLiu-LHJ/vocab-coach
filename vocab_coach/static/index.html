    文件格式

    JSON 根节点是对象数组，每条例句包含英文和中文翻译。

    [
  {
    "word": "serendipity",
    "translation": "意外的美好发现",
    "origin_translation": "A pleasant chance discovery.",
    "phonetic_us": "/ˌserənˈdɪpəti/",
    "phonetic_uk": "/ˌserənˈdɪpəti/",
    "examples": [
      {"sentence": "It was pure serendipity.", "translation": "这纯属意外之喜。"}
    ]
  }
]

    CSV 使用六列，其中 examples 单元格填写同样的 JSON 对象数组。
